# Online Store
Это проект интернет-магазина, разработанный с использованием Django. Проект создается в рамках учебного курса.
# Описание проекта

Данный проект представляет собой веб-приложение для отображения каталога товаров с возможностью просмотра подробной информации о каждом товаре.

## Функциональность

1. **Главная страница**:
   - Приветственное сообщение.
   - Список товаров с кратким описанием (ограничение в 100 символов).
   - Ссылки для перехода на страницу с подробной информацией о товаре.
   
2. **Страница подробного описания товара**:
   - Полное описание товара.
   - Изображение (или заглушка, если изображение отсутствует).
   - Категория, к которой относится товар.
   - Цена и дата добавления.
   
3. **Навигация**:
   - Меню с категориями товаров.
   - Страница контактов с формой обратной связи.
   
4. **Шаблоны Django**:
   - Используется базовый шаблон `base.html`, содержащий шапку, подвал и стили.
   - Главная страница `home.html` наследует базовый шаблон.
   - Подшаблон меню `menu.html`, который включается в другие шаблоны.
   
## Технологии

- **Django 5.1.5** — серверный фреймворк.
- **Bootstrap 5.3.0** — стилизация и адаптивная верстка.
- **HTML, CSS** — структура и оформление страниц.
- **Python 3.12.6** — язык программирования проекта.

## Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-repository.git
   cd your-repository
   ```

2. **Создайте виртуальное окружение и установите зависимости**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Примените миграции и запустите сервер**:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```

4. **Откройте в браузере**:
   ```
   http://127.0.0.1:8000/
   ```

## Работа с медиафайлами (изображениями товаров)

- В настройках проекта должен быть указан путь для хранения загруженных изображений.
- Если у товара нет изображения, в шаблоне выводится заглушка.
